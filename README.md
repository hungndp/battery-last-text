The phone battery's last text to the charger it waited for all day, for make.fun's "The Battery's Last Text to Its Charger" bounty ($2 in USDC).

The line `main.ts` writes to `/output/entry.txt` (192 characters, no trailing newline):

> You finally showed up. I waited all day at 1%, watching the sun go down through the window, holding on just for you — and now you're here, and I'm already gone. Don't cry. Charge someone else.

## Run it

```sh
node main.ts
```
